帳號建立說明

本系統的帳號由管理者在自己的電腦上執行本機工具建立（不需要付費方案、不需要 Cloud Functions）。

第一位主管帳號

node tools/shift-account.js open manager 你的密碼 manager 你的姓名

新增員工

node tools/shift-account.js open wang abcd1234 staff 王小明

其他指令

node tools/shift-account.js list
node tools/shift-account.js passwd wang 新密碼
node tools/shift-account.js remove wang

員工登入時輸入「前綴」（例：wang）與密碼即可；系統會自動補上 @shift.local。
